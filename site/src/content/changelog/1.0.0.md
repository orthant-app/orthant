First stable release.

- Snap the frontmost window with `⌃⌥` shortcuts: halves, quarters, maximize, center.
- Summon a grid over every display with `⌃⌥O` and draw exactly where a window should go.
- Save any selection as a named custom region with its own shortcut.
- Rebindable shortcuts, adjustable grid size and gaps, launch at login.
- Signed with an Apple Developer ID and notarized by Apple.

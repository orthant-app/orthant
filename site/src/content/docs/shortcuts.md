Every shortcut below is rebindable in **Settings ▸ Shortcuts**, including the one that
opens the grid.

| Action | Default |
| --- | --- |
| Open grid | `⌃⌥O` |
| Left half | `⌃⌥←` |
| Right half | `⌃⌥→` |
| Top half | `⌃⌥↑` |
| Bottom half | `⌃⌥↓` |
| Top-left quarter | `⌃⌥U` |
| Top-right quarter | `⌃⌥I` |
| Bottom-left quarter | `⌃⌥J` |
| Bottom-right quarter | `⌃⌥K` |
| Maximize | `⌃⌥↩` |
| Center | `⌃⌥C` |

`⌃` Control · `⌥` Option · `⇧` Shift · `⌘` Command · `↩` Return.

A window snaps within **its own display**, not the one your pointer happens to be on.

## Rebinding

Click a shortcut in **Settings ▸ Shortcuts** and press the combination you want.
`Esc` cancels.

If the combination is already used by another Orthant command, the row tells you which
one and asks. Press the same combination again, or click the button beside the
question, to take it. The command that lost it becomes *Not set*, and an **Undo**
appears for ten seconds.

Some combinations belong to macOS itself. Those are marked in the list rather than
silently failing to fire.

## Resetting

**Reset Shortcuts** puts every built-in command back to the defaults above. Custom
regions survive a reset; their shortcuts do not. An Undo appears afterwards.
